# Shadow Safety Boundary

Shadow fills are simulated or proxy evidence and are never broker-confirmed. A shadow session needs
no Kotak credential. The ordinary build cannot construct a live router. Any negative live
invocation must fail before a socket, HTTP client, broker adapter, or authentication object exists.

Data/Dhan remains the sole market-observation authority. Kotak order/trade/position updates are
execution evidence only and are not market-data ingestion.
