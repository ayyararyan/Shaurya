# Shaurya research instructions

## Mandatory data preflight

Before starting, extending, or reporting a new alpha-research experiment,
confirm the active requested data period from the user.

- The standing user instruction is to use the available **August data** for new
  alpha research.
- Do not default to January/February archives for convenience or for a
  train/test split.
- If a holdout is needed, split August chronologically: earlier sessions for
  selection and later sessions for a frozen evaluation.
- Use another period only with explicit user approval, or after explaining a
  technical impossibility and receiving direction.
- Do not treat an incomplete or still-open current session as valid unless the
  user has confirmed it is valid.

Read `research/docs/AUGUST_DATA_RULE.md` before designing the experiment; it
contains the fuller version of this rule.
