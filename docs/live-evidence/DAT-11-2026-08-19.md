## Addendum — solo parsed-row rate

The accepted ceiling candidates showed nearly invariant per-instrument parsed-row delivery: the
NIFTY and BANKNIFTY controls each produced 116 rows in almost every 15-second window, including
NIFTY's 116 rows inside the 50-instrument subscription. To test a per-instrument delivery cap
from shared socket bandwidth or an unconstrained event rate, NIFTY-Aug2026-FUT (`58072`) was then
subscribed **alone** four times. Each run used a fresh socket and exactly one one-instrument
message.

| Fresh solo run | Window (IST) | Parsed rows / 15 s | Rows/s | Ratio to 50-instrument reference |
|---:|---|---:|---:|---:|
| 1 | 11:06:44–11:07:00 | 116 | 7.73 | 1.000 |
| 2 | 11:07:00–11:07:16 | 120 | 8.00 | 1.034 |
| 3 | 11:11:06–11:11:22 | 114 | 7.60 | 0.983 |
| 4 | 11:11:22–11:11:38 | 114 | 7.60 | 0.983 |

The first artifact predeclared that counts within ±10% of 116 would imply a per-instrument rate
cap. That rule was **superseded before final handoff** because it treated each parsed depth row as a
distinct publication event. DAT-16 grouped rows by receive timestamp and showed that one fixed
500 ms snapshot arrives as about 4.17 same-timestamp rows. The corrected second artifact therefore
separates `unchanged-solo-row-rate` from the cap-versus-event conclusion.

**Addendum conclusion: not discriminated.** All four solo counts are within 3.4% of the
50-instrument reference, so removing 49 instruments did not materially change the **parsed-row**
rate. This rules out shared socket bandwidth collapse as the cause of the invariant count, but the
solo count itself does not distinguish a per-instrument cap from a true event rate because rows are
not publication events. DAT-16 provides the discriminating evidence: the 20-level channel is a
fixed **2.00 snapshot bursts/s**, approximately **500 ms** publication clock. The ~8 rows/s count
is an encoding artifact, neither a rate cap nor an event rate.

The direct implication for D23 is a 500 ms netting window. The number and order of exchange events
inside each snapshot interval remain unidentified; queue-ahead and cancellation/trade
decomposition must carry that partially identified interval rather than treating each parsed row
as an underlying event.

**Residual risk:** the solo runs occurred about 55–60 minutes after the 50-instrument reference,
so they do not hold latent market activity fixed. DAT-16's cadence finding is verified only for
depth20 on two front-month futures in one healthy morning window; depth200, options, other times,
and the physical source of the 500 ms clock remain unmeasured. Raw credential-free artifacts:
`dat11-solo-rate-addendum.json` (preliminary interpretation invalidated) and
`dat11-solo-rate-addendum-v2.json` (corrected; `conclusion: not-discriminated`) in the local ignored
`data/live-evidence/2026-08-19/` store.
