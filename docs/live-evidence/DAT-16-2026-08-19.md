# DAT-16 live evidence — 2026-08-19

## Finding

**Dhan's 20-level depth channel is a fixed 500 ms snapshot feed, not an event feed.**

This was found by OpenClaw while verifying DAT-15, not by the DAT-11..15 run agent. It
corrects a factual premise carried in `D23` and in the DAT-14/DAT-15 write-ups, where the
observed ~8 packets/second was read as an event rate subject to coalescing.

## Measurement

Source: the two healthy DAT-14 captures of 2026-08-19, 10:23–10:33 IST, NIFTY and BANKNIFTY
August futures, 597.9 s each, zero reconnects. Depth rows were grouped by distinct receive
timestamp.

| Quantity | NIFTY Aug fut | BANKNIFTY Aug fut |
|---|---:|---:|
| depth20 tape rows | 4,982 | 4,984 |
| Row rate | 8.33 /s | 8.34 /s |
| **Distinct receive timestamps (bursts)** | **1,195** | **1,195** |
| **Burst rate** | **2.00 /s** | **2.00 /s** |
| Rows per burst (mean) | 4.17 | 4.17 |
| Burst gap p05 / p50 / p95 (ms) | 496 / 501 / 506 | 495 / 501 / 506 |
| Bursts changing top-of-book price | 145 (0.24 /s) | 399 (0.67 /s) |
| Rows changing any top-of-book field | 525 (0.88 /s) | 812 (1.36 /s) |

The burst gap distribution is a metronome, not a distribution: p05 496 ms, p50 501 ms, p95
506 ms, with 1,079 of 1,194 NIFTY gaps and 1,050 of 1,194 BANKNIFTY gaps falling in the
500–550 ms bin. Two independent instruments produced **exactly 1,195 bursts** each.

The ~8.3 rows/second figure is an encoding artifact: one book state is delivered as ~4.17
tape rows within a single receive timestamp. On every classified print in these tapes,
`|trade_quote_bid_receive_ts − trade_quote_ask_receive_ts|` is **0.0 ms** — the two BBO legs
always arrive in the same burst and are never interleaved.

## Reconciliation with DAT-15

Under uniform print arrival inside a fixed snapshot interval of length `T`, the backward age
of the last book and the forward wait to the next book each have median `T/2` and sum to `T`.
DAT-15 measured, on the healthy core, a median causal quote age of **238.7 ms** and a median
post-print BBO delay of **258.5 ms**; these sum to **497.2 ms**, against a measured cadence of
**501 ms**. Healthy-core maximum quote age was 567.4 ms, i.e. approximately one period.

DAT-15's quote-age distribution is therefore **almost entirely snapshot phase, not
cross-channel clock drift**. It is a correct measurement of the operative staleness, but it
must not be read as an alignment error that better channel synchronisation could reduce.

The Quote/Full channel is *not* on a fixed cadence: distinct-timestamp rate 1.22 /s (NIFTY)
and 1.66 /s (BANKNIFTY), gap p05 71–495 ms, p50 557–875 ms, p95 ~1,140 ms, with a dispersed
mode. Prints and depth run on genuinely different clocks; only depth is a metronome.

## Consequences

1. **`D23` premise amended.** `D23` states "at roughly eight packets per second several
   events net into one observed delta". The correct statement is **two book states per
   second**: every event between consecutive snapshots is netted, and the blind window is
   **500 ms**, not ~125 ms. Bound width in the partially-identified queue-ahead is set by a
   500 ms window. `D23`'s structure — bounded, not unidentified — is unaffected; its width is
   materially worse than assumed.
2. **`EXE-10` is harder than scoped.** A bounded queue-position estimator on 2 Hz snapshots
   cannot observe the add/cancel/trade sequence within a window; it observes only the net
   delta across 500 ms.
3. **`EXE-09` inputs are degraded.** Huang–Lehalle–Rosenbaum intensities conditional on queue
   size are estimated from level deltas that are 500 ms-netted, not from an event stream.
4. **The touch is nearly static at this resolution.** Best bid/ask *price* changes 0.24–0.67
   times per second. Most snapshots carry no top-of-book price information at all.
5. **The queued "~8/s rate cap" interpretation is answered by timestamp grouping.** The
   constant 116-rows-per-15 s reading seen across DAT-11/12/13 runs is a clock
   (15 s × 2 bursts/s × ~4 rows), not a bandwidth cap and not a true event rate. The solo test was
   nevertheless run concurrently before this correction reached the run agent: four fresh-socket
   windows returned 116, 120, 114, and 114 rows. That rules out shared-socket bandwidth collapse
   but is correctly `not-discriminated` for cap versus event rate when considered alone.

## Scope and residual gaps

Verified for depth20 on two front-month index futures in one 10-minute morning window with
zero reconnects. **Not** verified for: depth200 cadence, options, other times of day, or
periods containing reconnects. Whether the 500 ms cadence is a Dhan publication interval, a
broker-side aggregation, or an NSE-side snapshot is **not identified** by this measurement.

## Reproduction

Group `event_type == "depth20"` rows of
`data/live-captures/dat14-{nifty,banknifty}/*/tape_*.jsonl` by rounded `receive_ts` and take
successive differences of the distinct timestamps.
